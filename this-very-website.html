Overview

This website was built AI-assisted with Claude. Most of the process was prompt engineering: I started from an idea for a shape based template and iterated on it with Claude, keeping the full conversation history. The full code is in my personal website repository on GitHub, and the basic template I was given sits in its own repository.

Once I had a good template, I used what I learned from The Odin Project over the summer (HTML, CSS and JavaScript) to write parts by hand and edit the code and stylesheet to fit my choices. Claude helped with making the template, finding 6 font options, and the cursor interactivity.

My first prompt

"I want to start making my personal website, but I need you to generate me a working template that I can edit: three pages for home, my work and a specific project page template. Dig into a popping writing vibe, and please give about 5 options for font ideas. I like simple and straight-to-the-point designs with random shapes and waveforms, like the written continuous w all around. I love the simplicity of personal websites. Let's start with a nice popover hover JavaScript process though."
